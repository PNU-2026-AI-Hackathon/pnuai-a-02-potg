# AI 도구 활용 및 고도화

> 제7회 PNU 창의융합 AI 해커톤 · 융합트랙 2팀 · 팀 POTG

모이라는 AI를 최종 판단자가 아니라 **주민 의견과 도서관 프로그램 기획을 연결하는 보조 도구**로 활용하였다. 개발 과정에서는 코드 작성과 문서화를 보조하는 도구로, 서비스 내부에서는 기획안 초안 생성과 기존 프로그램 사례 탐색을 돕는 기능으로 사용하였다.

## 1. 활용한 AI 도구

| 구분 | 도구 | 활용 범위 |
| --- | --- | --- |
| 개발 보조 | ChatGPT / Codex | 요구사항 정리, 코드 초안 작성, 리팩터링, 오류 원인 분석, README·개발 문서 작성 |
| 서비스 탑재 | Google Gemini API | MOIRA STUDIO의 기획안 생성, 항목별 문장 다듬기 |
| 검색 고도화 | KURE-v1 / Sentence Transformers | 도서관 프로그램 사례 임베딩 및 유사 사례 검색 실험 |
| 데이터 보강 | NAVER Cloud CLOVA OCR | 이미지·스캔 PDF 안내문의 텍스트 추출 |

## 2. 활용 범위

### 2.1. 개발 과정에서의 활용

AI 코딩 도구는 프론트엔드 화면 구성, 백엔드 API 구현, Prisma schema 검토, 데이터 수집·정제 배치, 테스트 코드와 문서 초안 작성에 활용하였다. 단, 서비스 요구사항, 기능 우선순위, 데이터 구조, 최종 코드 반영 여부는 팀원이 결정하였다.

### 2.2. 서비스 내부 AI 기능

MOIRA STUDIO는 주민 아이디어 또는 사서가 입력한 조건을 바탕으로 프로그램명, 기획 의도, 대상, 운영 방식, 회차 구성, 기대 효과 등을 구조화한 기획안 초안을 생성한다. 생성 결과는 바로 확정되지 않으며, 사서가 직접 수정하거나 필요한 항목만 AI로 다시 다듬을 수 있도록 구성하였다.

또한 기존 도서관 프로그램 데이터를 정제하고, KURE-v1 임베딩과 pgvector 기반 검색을 실험하여 유사 프로그램 사례를 기획 참고자료로 활용할 수 있도록 고도화하였다. PDF/HWP 텍스트 추출과 CLOVA OCR은 첨부파일에 포함된 세부 프로그램 정보를 보강하는 데 사용하였다.

## 4. 한계와 운영 원칙

AI가 만든 기획안은 참고 초안이며, 프로그램 개설 여부나 최종 내용은 사서와 프로그램 기획 담당자가 결정한다. 검색·OCR 결과 역시 원문 품질과 추출 정확도에 영향을 받을 수 있으므로, 모이라는 AI 결과를 자동 확정하지 않고 사람이 확인하고 수정할 수 있는 흐름을 유지하였다.
