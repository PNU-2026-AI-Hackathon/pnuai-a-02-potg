## 기능 개요
- MOIRA Studio의 기존 입력 화면에서 사용자가 기획 메모를 작성하면, Gemini API를 호출해 정해진 형식의 프로그램 기획서 초안을 생성하고 수정 화면에 바로 보여줍니다.
- 이번 범위에서는 초안 생성과 화면 반영까지만 구현하고, 저장/버전 관리 DB 연동은 후속 작업으로 분리합니다.

## 참고 사항 및 관련 링크
- 현재 데모 문서와 편집 화면 흐름을 활용
- DB 저장과 히스토리 관리는 2차 작업으로 진행
- 출력 형식은 제목, 개요, 대상, 운영 기간, 세부 내용, 기대 효과처럼 고정된 섹션으로 제한

## Gemini API 스펙
- 입력값: 사용자의 기획 메모, 선택한 조건, 참고 의제 정보
- 호출 방식: 서버에서 Gemini API를 호출하고, 프론트엔드는 생성 요청만 전송
- 응답 방식: 아래 고정 포맷의 JSON을 반환하도록 프롬프트에 명시
- 실패 처리: 응답 파싱 실패 또는 API 오류 시 안내 메시지 노출

## 기획서 고정 출력 포맷
- title: 기획서 제목
- summary: 기획 의도와 핵심 요약
- target: 대상 및 참여 인원
- duration: 운영 기간과 회차
- details: 회차별 세부 운영 내용
- expectedEffects: 기대 효과
- notes: 준비물, 예산, 홍보 등 추가 참고 사항
