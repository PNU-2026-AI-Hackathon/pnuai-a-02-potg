## 작업 개요

프로그램 게시판에 올라오는 프로그램들의 신청기간을 한눈에 볼 수 있는 캘린더 화면(`/programs/calendar`)을 추가했습니다. 헤더의 "프로그램 게시판" 메뉴에 마우스를 올리면 "우리동네 이야기"처럼 서브메뉴가 펼쳐지고, 그 안에서 캘린더로 들어갈 수 있습니다. 함께 진행하던 신규 프로그램 5건 반영과 프로그램 게시판 문구 정리도 이 브랜치에 포함했습니다.

## 작업 내용

- [x] `/programs/calendar` 페이지 추가 — 월 단위 캘린더, 신청기간을 이어진 막대로 표시
- [x] 헤더 "프로그램 게시판"을 hover 드롭다운으로 변경 (전체 프로그램 / 캘린더), 모바일 메뉴에도 하위 링크 추가
- [x] 한 주에 자리가 모자란 프로그램은 "+N"으로 접되, 모집중·모집예정을 마감보다 먼저 배정해 우선순위로 접히도록 처리
- [x] 하루에 5개 넘게 겹치는 날은 "+N 더보기"를 눌러 그날 일정 전체를 팝오버로 확대해서 볼 수 있음 (자바스크립트 없이 네이티브 `<details>`로 구현, 제목-상태색 점 목록). 같은 `name`으로 묶어 다른 날짜의 더보기를 열면 이전 것이 자동으로 닫힘
- [x] 오른쪽 "신청 가능한 프로그램" 사이드 목록은 최종적으로 제거하고, 캘린더 격자가 컨테이너 너비(최대 1180px)를 그대로 쓰도록 가로로 넓게 조정 — 접힌 일정은 "+N 더보기"로 충분히 확인 가능
- [x] 캘린더 디자인을 사이트 톤(브랜드 그린 · 카드형 · 그림자)에 맞춰 현대적으로 정리 (오늘 날짜는 원형 표시, 막대는 옅은 톤 칩 + 좌측 강조선)
- [x] "공공예약에서 보기" → "공공예약 서비스에서 보기"로 문구 통일 (프로그램 목록 카드, 캘린더 막대 aria-label)
- [x] 프로그램 게시판 타이틀 "우리 동네에서 열리는 프로그램들." 끝 마침표 제거
- [x] 금정구 작은도서관 프로그램 게시판 신규 크롤링분 5건을 DB에 추가 (기존 350건은 변경 없음)

## 구현 범위

### 포함
- `/programs/calendar` 신규 페이지 및 캘린더 계산 로직(`lib/program-calendar.ts`)
- `SiteHeader` 드롭다운 메뉴, 관련 CSS
- `/programs` 목록 카드 링크 문구·타이틀 수정

### 제외
- 캘린더에서 날짜/막대 클릭 시 자체 상세 페이지 이동은 다루지 않음 (기존 목록 카드와 동일하게 공공예약 서비스로 바로 이동)
- 프로그램 데이터 크롤링·정제 파이프라인 자체는 손대지 않음 (신규 5건만 안전하게 추가)

## 테스트 방법

1. `apps/backend`, `apps/frontend` 각각에서 `npm run dev` 실행 (백엔드 DB 연결 필요)
2. 브라우저에서 헤더의 "프로그램 게시판"에 마우스를 올려 서브메뉴에서 "캘린더" 클릭, 또는 `/programs/calendar` 직접 접속
3. 이전 달/다음 달 이동, "오늘로 이동" 링크 확인
4. 신청기간이 겹치는 주에서 막대가 잘 이어지는지, "+N 더보기" 배지가 뜨는지 확인
5. "+N 더보기"를 눌러 그날 일정 팝오버가 뜨는지, 다른 날짜의 더보기를 누르면 이전 팝오버가 자동으로 닫히는지 확인
6. `/programs` 목록 카드의 "공공예약 서비스에서 보기" 문구, 타이틀 마침표 제거 확인
