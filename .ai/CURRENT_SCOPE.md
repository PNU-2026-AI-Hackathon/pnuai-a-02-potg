# 현재 MVP 범위

이 문서는 모이라의 현재 개발 범위를 정의하는 최종 기준이다. 기획이나 우선순위가 변경되면 이 문서를 함께 갱신한다.

## 현재 포함 범위

- Next.js 기반 메인 페이지와 서비스 화면
- 회원가입, 로그인, 로그아웃, 현재 사용자 확인
- 사용자 관심분야 선택과 저장
- 작은도서관 행사 및 소식 게시판
- 자유게시판
- 지역 제안 게시판
- 도서관, 공지, 프로그램 정보 조회
- Vercel, EC2, RDS를 사용하는 운영 구조 유지

포함 범위라고 해서 모두 동작 검증 또는 DB 연동이 완료되었다는 뜻은 아니다. 상세 상태는 `IMPLEMENTATION_STATUS.md`를 따른다.

## 게시판 기준

최종 게시판 구조는 다음 `/community/*` 경로다.

- `/community/library-news`: 작은도서관 행사 및 소식
- `/community/free`: 자유게시판
- `/community/proposals`: 지역 제안 게시판

`/board`와 `/api/posts`는 초기 연동 실험 또는 레거시 구현이다. 이번 문서 작업에서는 삭제하거나 통합하지 않으며, 향후 `/community/*` 기준으로 통합한다.

## AI 및 프로그램 기획 범위

- AI 프로그램 기획 기능의 이름은 **모이라 스튜디오**다.
- AI 의제 분석과 모이라 스튜디오는 현재 제품 목표에 포함되지만 아직 구현되지 않았다.
- pgvector, LangChain.js, RAG, AI API 연동은 현재 구현되었다고 간주하지 않는다.
- 해당 기술 도입 여부와 상세 구조는 별도 이슈 및 결정으로 확정한다.

## MVP 제외 범위

대학생 봉사자 모집 및 매칭 기능은 현재 MVP에서 제외한다.

다음 코드는 과거 계획의 잔여 mock 코드로 분류한다.

- Express `/api/volunteers`
- volunteer mock 데이터
- summary의 봉사 관련 항목

이번 범위에서는 삭제하지 않는다. 제거 여부는 별도 이슈에서 결정한다.

## 이번 문서 체계 구축 범위

- `AGENTS.md`
- `.ai/*`
- `README.md` 정리

Issue/PR 템플릿, package.json, 기능 코드, workflow, 자동화 설정은 이번 범위에 포함하지 않는다.

## 현재 개발 우선순위

1. 메인 페이지 개선
2. `/community/*` 게시판 DB 연동
3. AI 의제 분석
4. 모이라 스튜디오
5. 프로그램 관리

이 순서는 현재 MVP 기준이며 기획 변경 시 함께 수정한다.
