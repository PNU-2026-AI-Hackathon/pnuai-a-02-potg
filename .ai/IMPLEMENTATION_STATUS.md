# 구현 상태

## 상태 기준

- **코드 경로 구현됨**: UI, API, 데이터 계층의 코드 경로가 존재함. 실제 환경 동작 검증을 의미하지 않음.
- **부분 구현**: 목표 기능 중 일부 경로만 구현됨.
- **mock**: 정적 또는 메모리 데이터에 의존함.
- **UI 골격**: 화면 구조는 있으나 실제 데이터·행위 연동이 부족함.
- **실행 검증 필요**: 빌드, lint, DB 연결 또는 API 실행 확인이 수행되지 않음.
- **미구현**: 목표만 있고 대응 구현이 확인되지 않음.
- **MVP 제외**: 현재 개발 범위 밖임.

관련 이슈/PR은 로컬 Git 기록에서 확인된 번호만 기록한다. 번호가 없는 항목은 향후 작업 이슈가 생성될 때 갱신한다.

## 게시판 통합 방향

`/community/*`가 최종 기준이다. `/board`와 `/api/posts`는 이번 작업에서 유지하며, 이후 별도 이슈에서 `/community/*` 기준 DB 모델과 API를 설계한 뒤 통합 또는 제거 범위를 결정한다.

## 상태 갱신 규칙

- 기능을 변경한 PR 번호를 관련 이슈/PR 컬럼에 추가한다.
- 코드만 작성한 경우 동작 검증 완료로 표현하지 않는다.
- mock을 DB 구현으로 교체하면 상태와 비고를 함께 갱신한다.
- MVP 범위가 바뀌면 `CURRENT_SCOPE.md`도 함께 수정한다.
