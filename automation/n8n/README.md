# 금정구 작은도서관 프로그램 크롤링

이 디렉터리는 금정구 작은도서관 프로그램 정보를 수집하는 n8n 워크플로우를 관리합니다. 워크플로우는 프로그램 목록과 각 프로그램의 상세 페이지를 순서대로 요청하고, 수집한 정보를 공통 DTO 형태로 정리합니다.

## 수집 범위

- 목록 페이지 페이지네이션
- 상세 페이지 순차 요청
- HTTP 요청 실패 시 재시도
- 프로그램 기본정보, 강사, 모집인원, 신청인원, 교육 기간, 장소
- 회차별 프로그램 내용
- 첨부파일 이름, URL, 확장자

HWP, PDF, 이미지 첨부파일의 실제 내용 분석은 이 워크플로우의 범위에 포함하지 않으며 후속 작업으로 진행합니다.

## n8n에서 가져오기

1. n8n의 워크플로우 화면에서 **Import from File**을 선택합니다.
2. `geumjeong-small-library-crawler.json` 파일을 선택합니다.
3. 가져온 노드와 연결, 요청 URL 및 실행 옵션을 확인합니다.
4. 테스트 실행으로 목록 및 상세 페이지 응답과 최종 출력 형식을 확인합니다.

워크플로우 JSON에 Credential 값, API 키, 비밀번호, 인증 토큰, 쿠키 등 민감정보를 직접 저장하거나 커밋하지 마세요. 인증이 필요한 경우 n8n의 Credential 관리 기능을 사용하고, 내보낸 JSON에도 실값이 포함되지 않았는지 확인해야 합니다.
